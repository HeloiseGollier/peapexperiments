# Test Certificates and Configurations

## Certificate Generation

The certificates are generated using [scripts from FreeRadius](https://github.com/FreeRADIUS/freeradius-server/tree/v3.0.x/raddb/certs).
These scripts are available in the `certs/gen-scripts/` directory.

## Usage

All private certificates must use the password "whatever" without the quotes. The CA, server, and client use this as the password.
